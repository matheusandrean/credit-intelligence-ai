# Visual identity

Provisional palette for Matheus Marcondes's portfolio, pending confirmation of GovernandoAI's official brand colors.

| Role | Color |
| --- | --- |
| Navy / primary | `#0B1628` |
| Cyan / accent on navy | `#22D3EE` |
| Teal / accent on white | `#0E7490` |
| Body text | `#172B44` |
| Muted text | `#52647A` |
| Light surface | `#F4F8FC` |

Use local SVG assets, clear typography and restrained accents. Keep risk bands and alert colors semantic; cyan is a brand accent, not a risk category. Retain text labels alongside chart colors. This palette is not an official GovernandoAI brand specification.
